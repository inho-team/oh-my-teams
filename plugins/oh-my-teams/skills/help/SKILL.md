# oh my teams 도움말

일반적인 개발 요청은 현재 세션에서 직접 처리한다. 여러 세션의 협업이나 지속 감독이 필요한 경우에만 `kickoff`를 사용한다. Orca 워크트리마다 소유 세션 하나가 작업을 책임하며, 별도의 이사·PM·Worker 조직을 만들지 않는다.

| 스킬 | 사용 시점 |
|---|---|
| `kickoff` | 현재 소유 세션에서 팀 작업을 시작하거나 재개할 때 사용한다. |
| `consult` | 소유 세션이 advisor, lawyer 또는 auditor 목적의 읽기 전용 서브에이전트를 부를 때 사용한다. |
| `status` | Orca와 Git에서 현재 실행 상태를 확인할 때 사용한다. |
| `close` | 결과를 검증하고 전달하며 자식 워크트리를 회수할 때 사용한다. |
| `disband` | 실패하거나 취소된 작업을 안전하게 중단할 때 사용한다. |
| `fluent-korean` | 한국어 문서와 보고서의 문체를 다듬을 때 사용한다. |

자세한 소유권과 검토 규칙은 [세션 소유권 구조](../../references/architecture.md)에 있다. 2.x의 조직과 kickoff 기록은 자동으로 3.x 실행에 이어 붙이지 않는다.
