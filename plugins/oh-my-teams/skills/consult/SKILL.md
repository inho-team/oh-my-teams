# 전문 서브에이전트 호출

이 스킬은 현재 Orca 워크트리의 소유 세션이 사용한다. advisor, lawyer, auditor는 상설 조직 역할이나 별도 워크트리가 아니다. 호출자는 [세션 소유권 구조](../../references/architecture.md)에 따라 작업을 계속 소유한다.

호스트가 서브에이전트를 제공하면 목적과 읽을 자료를 좁혀 호출한다. 제공하지 않으면 소유 세션이 같은 검토를 직접 수행하되, 독립 검토를 수행했다고 주장하지 않는다. 서브에이전트에게 워크트리·브랜치·커밋 생성, 파일 편집, 재위임, 사용자 연락과 승인 기록을 맡기지 않는다.

## advisor

계획, 설계 또는 장애 대응의 선택지가 실제로 갈릴 때 호출한다. 질문 하나, 관련 사실, 선택지와 제약을 전달한다. 답변에는 추천안, 근거, 반대 근거와 확인하지 못한 점을 요구한다. 최종 결정은 소유 세션이 내린다.

## lawyer

요구 사항이나 검토 이의에 대한 응답을 준비할 때 호출한다. 원문, 이의, 관련 커밋과 증거를 전달하고 각 주장에 대한 근거와 응답 초안을 요구한다. 타당한 이의는 인정하게 하며, 확인되지 않은 사실은 분리하게 한다. 소유 세션이 실제 파일을 확인하고 응답한다.

## auditor

수용 기준과 구현 결과를 독립적으로 대조할 필요가 있을 때 호출한다. 구현에 참여하지 않은 다른 실행 ID가 고정된 커밋을 읽게 한다. 기준별로 확인한 근거, 재현 가능한 결함, 누락과 남은 불확실성을 보고하게 한다. 소유 세션은 원문 결과를 보존하고 지적을 해결한 뒤 새 커밋을 다시 검토받는다. 같은 실행에서 자기 결과를 독립 검토로 승인하지 않는다.

서브에이전트가 읽기 전용으로 검토하더라도 같은 워크트리의 편집 소유권은 호출자에게 남는다. 검토 기준이 되는 커밋이 바뀌면 이전 검토를 최신 결과의 승인으로 사용하지 않는다.
