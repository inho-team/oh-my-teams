# team-adjust 호환 별칭

이전 호출과의 호환 진입점이다. [team-adjust](../team-adjust/SKILL.md)을 전체 읽고 같은 절차를 수행한다. 새 안내와 후속 호출에는 `team-form`, `team-kickoff`, `team-status`, `team-adjust`, `team-close`, `team-disband` 이름을 사용한다.
