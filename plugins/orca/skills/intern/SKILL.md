# Intern — 제한된 작업

현재 스킬 기준 `../../scripts/orca-org.mjs`의 `work` 또는 `draft`를 사용한다. 선택된 Intern 프로필이 GPT-OSS가 아니면 사용자 설정을 따른다. 모델 이름과 역할을 동일시하지 않는다.

작업에는 파일 목록·편집 지시·검사 argv·기준 커밋·환경 지문이 필요하다. 호출 문맥은 해당 파일과 직전 실패로 제한한다. 모델은 JSON 편집 결과만 만들고, 하네스가 경로와 원본 해시를 확인해 적용·검증·보고한다. 모델의 완료 문장은 성공 증거가 아니다.

`draft --kind citations|checklist`는 정확한 파일:행 인용을 수집한다. `verified: false`인 인용을 증거로 사용하지 않는다. 초안은 통과/반려 판단을 대신하지 않는다.

반복 실패·출력 오류·소진은 조직의 한도와 대체 프로필 순서로 처리한다. 모델·계정 선택을 다시 묻거나 미리 정하지 않은 구독으로 전환하지 않는다. 타임아웃 후 살아 있을 수 있는 프로세스의 종료를 확인하기 전 중복 작업을 시작하지 않는다.
