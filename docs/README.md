# 개발 문서 안내

현재 프로젝트를 수정할 때에는 [AI 작업 안내](AI_GUIDE.md)에서 작업에 필요한 파일과 검사를 찾고, [프로젝트 분석](PROJECT_ANALYSIS.md)에서 구조·계약·위험의 근거를 확인한다. 두 문서는 `4d423a9`의 분석과 3.3.0의 작업 흐름 개선을 반영한다. 실제 HEAD와 외부 실행 결과는 작업할 때 다시 확인한다.

현재 제품은 Orca 워크트리의 소유 세션을 중심으로 동작하는 3.x 스킬 패키지다. 설치되는 규칙은 `plugins/oh-my-teams/` 안에서 관리하고, 이 디렉터리에는 개발 설명과 분석을 둔다. 문서의 제안이나 저장된 평가 결과를 실제 실행 상태·사용자 권한의 근거로 사용하지 않는다.

작업 소유권의 정본은 설치되는 [세션 소유권 구조](../plugins/oh-my-teams/references/architecture.md)이며 실패 판단의 정본은 [실패 상황의 판단 기준](../plugins/oh-my-teams/references/failure-handling.md)이다. 이 목차는 정본의 위치를 안내하며 별도 운영 정책이나 실행 등록부를 만들지 않는다.
