# 다른 세션에 전달할 후속 작업

2026-10-15에 현재 Windows 세션에서 접근할 수 없는 환경과 미검증 장애 조건을 분리했다. 사용자는 Mac·Linux가 다른 Orca에 있으므로 해당 세션이 수행할 수 있게 작업별 Markdown을 남기도록 요청했다. 아래 항목은 구현 완료나 검증 성공을 뜻하지 않는다.

| 작업 | 상태 | 필요한 환경 |
|---|---|---|
| [macOS 실제 호스트 연동](native-host-macos.md) | 미착수이며 Mac 세션에서 인수해야 한다. | macOS의 실제 Claude·Codex·Orca가 필요하다. |
| [Linux 실제 호스트 연동](native-host-linux.md) | 미착수이며 Linux 세션에서 인수해야 한다. | Linux의 실제 Claude·Codex·Orca가 필요하다. |
| [실제 전송 단절](transport-disconnect.md) | 미착수이며 지원되는 격리 경로를 확보해야 한다. | 폐기 가능한 Orca 대상과 관측 가능한 전송 경로가 필요하다. |
| [전원 장애 내구성](power-loss-durability.md) | 미착수이며 별도 격리 실험이 필요하다. | 작업 데이터가 없는 VM과 강제 전원 차단 제어가 필요하다. |

인수하는 세션은 실제 `main` SHA, 설치 버전과 정책 해시부터 기록한다. 이 문서의 작성 버전은 3.0.8이며 미래 실행 버전을 고정하지 않는다. 작업은 해당 Orca 워크트리의 소유 세션이 수행하며 기존 세션의 기록이나 성공 여부를 추정하지 않는다. 완료 시 해당 작업 문서에 결과 파일과 커밋을 연결하고 상태를 갱신한다. 코드 변경은 종류에 맞는 브랜치에서 진행하고 병합 전에 현재 HEAD의 Linux·macOS CI를 확인한다.
