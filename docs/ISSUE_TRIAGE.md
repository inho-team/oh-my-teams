# 3.x 안정화와 열린 이슈 분류

2026-10-21에 열린 이슈 34건의 본문과 댓글을 `3.2.0`의 기준 커밋 `ee28b7463b1433d1a894503365740318b66dfa54` 및 당시 작업 파일과 대조했다. 사용자가 승인한 수정 대상은 현재 3.x다. 이번 변경의 패키지 버전은 `3.2.1`이다. 이 문서는 2026-10-21의 분류 기록이며, 원격 이슈의 댓글 작성·종료는 포함하지 않는다.

3.0에서 제거한 2.x 런타임은 이번에 복원하거나 수정하지 않는다. 아래의 **구버전 전용**은 현재 3.x에서 해당 실행 경로가 없다는 뜻이며, 2.x 결함을 수정했다는 뜻이 아니다. 구버전 실행은 해당 버전으로 종료해야 한다는 [이전 버전 정책](../README.md#2x에서-변경된-점)을 유지한다.

## 2026-10-21의 검증과 후속 처리

의존성 복원 전의 로컬 `npm run verify`는 설치 패키지 누락으로 실패했다. `npm ci` 후 변경 전 전체 검증은 성공했다. #133의 회귀 검사는 수정 전 POSIX 전용 경로를 진단하지 못해 실패하는 것을 확인했고, 수정 후 관련 테스트가 통과했다. 새 테스트 파일이 커밋되기 전에도 저장소 검사에서 실패하는 통합 사례를 포함했다.

macOS·Node 26.7.0에서 `npm run format`, `npm run sync`, `npm run lint`, `npm test`를 순서대로 실행해 모두 종료 코드 0을 확인했다. 전체 테스트 209개가 통과했으며 실패·취소·건너뜀은 0개다. 소스 검사와 설치·저장소 문서 검사, 버전 동기화 검사도 통과했다. 수정한 JavaScript 두 파일의 언어 서버 오류 진단과 `git diff --check`에는 오류가 없었다.

당시에는 변경을 커밋하거나 원격에 전달하지 않았으므로 새 Jenkins 빌드를 실행하지 않았다. 기준 커밋의 Jenkins 성공은 이 변경의 승인 근거가 아니다. 병합 전에는 최종 커밋의 Jenkins Linux·macOS 결과를 별도로 확인해야 한다. Windows 실행과 실제 호스트에서 자식 Goal·앱 연결·선택 창 행동을 재현하는 검증도 당시 수행하지 않았다.

원격 이슈에는 변경을 가하지 않는다. 후속으로 이슈를 정리할 때에는 현재 지침 보완, 구버전 전용 경로의 폐기, 기존 계약 반영과 외부 호스트의 미검증을 각각 구분하고 사용자의 이슈 처리 권한을 확인한다.
